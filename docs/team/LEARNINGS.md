# Learnings

- **2026-10-25 · Rules:** The engine, UI validator and supposedly independent test all shared the same incorrect Queens chess-diagonal rule. Read the published rule and test a counterexample; agreement between implementations is not evidence that the rule is right.
- **2026-10-25 · Difficulty:** All Sudoku levels originally allowed the same techniques; Pinpoint's synthetic overlap constraint excluded most of its content. Validate actual solving requirements and reachable content, rather than trusting labels, clue counts or bank size.
- **2026-10-25 · Gameplay:** Generator checks missed stuck hints, Murdoku's inability to unseat people, the reverse Crossclimb route, broken Patches hints, and missing drag samples. Exercise actual controls, normal completions and recovery from mistakes.
